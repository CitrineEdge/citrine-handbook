# Security Reporting

This repository contains public documentation, not Citrine's application source.
For a suspected security issue affecting Citrine, contact **support@citrineedge.com**
privately with a concise description, affected app version and non-sensitive
reproduction steps.

Do not open a public issue containing exploit details, credentials, account
records or another person's information. Do not send API keys, purchase tokens,
passwords or tax/banking documents. If a credential may be exposed, revoke it
through its issuing service; do not wait for a support reply to protect it.

This document does not authorize testing other people's accounts, intrusive tests
against production infrastructure, or access to private systems. It does not
establish a bug-bounty payment commitment or a guaranteed response time.

[Public security overview](https://citrineedge.com/security/)
