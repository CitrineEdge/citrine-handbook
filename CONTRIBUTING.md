Corrections, clearer explanations and reproducible documentation issues are
welcome. Keep proposed changes focused on a user task and cite an authoritative
source for version-sensitive product claims.

- Do not upload app or website source, strategy settings, production logs,
  account exports, credentials or private screenshots.
- Keep examples explicitly synthetic and unrelated to an actual account.
- Do not submit trading signals, return promises, referral spam or copied
  third-party articles.
- Use private support for account issues and SECURITY.md for suspected security
  problems. A public issue is not a private support ticket.

The website remains authoritative for current pricing, eligibility, privacy and
program terms. Changes to this handbook do not change app behavior or those terms.
