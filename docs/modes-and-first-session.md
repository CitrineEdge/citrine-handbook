# Citrine Modes And First-Session Checklist

## Pick The Responsibility, Not Just The Balance

| Mode | Starting point | Sends real orders? | Appropriate use |
| --- | --- | --- | --- |
| Paper | A hypothetical balance you choose | No | Learn the workspace and follow a simulated session without importing an API key |
| Shadow | Authenticated account inputs, followed by its own simulated session | No | Compare account-aware simulation with market conditions |
| Observation | Actual account view | No, including manual closes or protection management | Monitor the account without making this device an execution device |
| Standard | Actual account | Yes, when Complete and eligible trading access are active | Run live entries and eligible position management |

Backtesting is historical replay, not a fifth live-account mode. The Guided Demo
introduces the interface with an example account and does not require a trade.

## Before A Paper Session

- Open the Guided Demo from Support if the workspace is unfamiliar.
- Choose a starting balance and allocation deliberately. Keep those values if
  you plan to compare sessions later.
- Read the mode and runtime status. A displayed chart alone does not mean a
  session is running or that conditions qualify for an entry.
- Review the Edge details, result details and their explanatory sections rather
  than interpreting a single number out of context.
- Preserve the session's dates, mode and export when making comparisons.

## Before Account-Connected Use

- Confirm you are using the eligible Coinbase Advanced U.S. futures account,
  not a similarly named international or spot product.
- Follow the [current key setup](https://citrineedge.com/coinbase-api-setup/).
  Import credentials in the app, never into an issue, message or support form.
- View permission supports account access. Live trading also needs Trade.
  Citrine does not require Transfer, Receive or withdrawal permissions.
- Check validation, selected mode, allocation, available funds, capacity and any
  status requiring attention. An Edge condition marked ready is not a promise
  that an order will be submitted immediately.
- Keep the Android device powered, connected and configured for the app's
  background operation. A spare device is an option, not a requirement.
- Keep direct Coinbase access available for account checks or urgent action.

## Pause And Exit Are Different

**Pause** holds new entries; eligible live-position management can continue.
**Exit Citrine** stops the local runtime. It does not automatically close open
positions or cancel existing exchange orders.

Accepted Coinbase-hosted protection is different from on-device management.
Observation does not manage protection. After an interruption, verify the actual
runtime and exchange state rather than assuming trading resumed.
