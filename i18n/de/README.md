Praktische Dokumentation für **Citrine**, die lokal auf dem Gerät ausgeführte
Android-Trading-App für berechtigte BTC- und ETH-Perpetual-Futures auf Coinbase
Advanced, herausgegeben von Citrine Edge.

Beginnen Sie mit einer simulierten Sitzung, verstehen Sie die Zuständigkeit der
einzelnen Modi und lernen Sie, Ergebnisse zu lesen, ohne Trading-PnL, Kosten und
Funding zu verwechseln. Diese Anleitungen richten sich an Nutzer und Personen,
die das Produkt prüfen. Sie enthalten keinen Quellcode der App, Website, Strategie
oder Backend-Implementierung. Dies ist weder eine API-Integrationsbibliothek noch
ein herunterladbarer Trading-Bot.

## Anleitung auswählen

| Aufgabe | Anleitung |
| --- | --- |
| Zwischen Paper, Shadow, Observation und Standard wählen | [Modi und Checkliste für die erste Sitzung](docs/modes-and-first-session.md) |
| Einen Backtest mit einer simulierten oder echten Sitzung vergleichen | [Ergebnisse lesen und Kosten abgleichen](docs/reading-results.md) |
| Einen hilfreichen Bericht ohne Offenlegung von Kontodaten erstellen | [Sichere Fehlerdiagnose](docs/safe-troubleshooting.md) |
| Ein vermutetes Sicherheitsproblem vertraulich melden | [Sicherheitsmeldungen](SECURITY.md) |
