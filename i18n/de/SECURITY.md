Dieses Repository enthält öffentliche Dokumentation, nicht den Quellcode der
Citrine-Anwendung. Melden Sie ein vermutetes Sicherheitsproblem mit Citrine
vertraulich an **support@citrineedge.com**. Nennen Sie eine kurze Beschreibung,
die betroffene App-Version und Schritte zur Reproduktion ohne sensible Daten.

Eröffnen Sie kein öffentliches Issue mit Exploit-Details, Zugangsdaten,
Kontounterlagen oder Informationen über andere Personen. Senden Sie keine
API-Schlüssel, Kauftokens, Passwörter oder Steuer- und Bankunterlagen. Falls
Zugangsdaten offengelegt worden sein könnten, widerrufen Sie diese beim ausstellenden
Dienst. Warten Sie damit nicht auf eine Supportantwort.

Dieses Dokument erlaubt weder Tests an fremden Konten noch intrusive Tests gegen
Produktionsinfrastruktur oder den Zugriff auf private Systeme. Es begründet keine
Bug-Bounty-Zahlungszusage und keine garantierte Antwortzeit.
