Praktyczna dokumentacja **Citrine**, aplikacji do handlu na Androida działającej
na urządzeniu, przeznaczonej do obsługiwanych bezterminowych kontraktów futures
BTC i ETH na Coinbase Advanced, wydawanej przez Citrine Edge.

Zacznij od sesji symulowanej, poznaj zakres działania każdego trybu i naucz się
czytać wyniki bez mylenia PnL z handlu, kosztów i finansowania. Poradniki są dla
użytkowników i osób oceniających produkt; nie zawierają kodu źródłowego aplikacji,
witryny, strategii ani zaplecza. To nie jest biblioteka integracji z API ani
bot handlowy do pobrania.
