Questo repository contiene documentazione pubblica, non il codice sorgente
dell'applicazione Citrine. Per un sospetto problema di sicurezza che riguarda
Citrine, contatta in privato **support@citrineedge.com** con una descrizione
concisa, la versione interessata dell'app e passaggi di riproduzione privi di dati sensibili.

Non aprire una segnalazione pubblica contenente dettagli di exploit, credenziali,
registri di conto o informazioni di altre persone. Non inviare chiavi API, token
di acquisto, password o documenti fiscali e bancari. Se una credenziale potrebbe
essere stata esposta, revocala presso il servizio che l'ha emessa; non aspettare
una risposta dell'assistenza per proteggerla.

Questo documento non autorizza test sui conti altrui, test intrusivi
sull'infrastruttura di produzione o accessi a sistemi privati. Non istituisce
un impegno al pagamento di ricompense bug bounty né un tempo di risposta garantito.
