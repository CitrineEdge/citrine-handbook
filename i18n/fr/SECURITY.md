Ce dépôt contient de la documentation publique, pas le code source de l'application
Citrine. Pour un problème de sécurité présumé touchant Citrine, contactez en privé
**support@citrineedge.com** avec une description concise, la version de
l'application concernée et des étapes de reproduction sans données sensibles.

N'ouvrez pas de ticket public contenant des détails d'exploitation, des
identifiants, des données de compte ou des informations sur une autre personne.
N'envoyez pas de clés API, de jetons d'achat, de mots de passe ou de documents
fiscaux ou bancaires. Si un identifiant risque d'être exposé, révoquez-le auprès
du service qui l'a émis ; n'attendez pas une réponse de l'assistance pour le protéger.

Ce document n'autorise pas les tests sur les comptes d'autrui, les tests intrusifs
sur l'infrastructure de production ou l'accès à des systèmes privés. Il ne crée
aucun engagement de rémunération de type bug bounty ni délai de réponse garanti.
