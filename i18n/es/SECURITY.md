Este repositorio contiene documentación pública, no el código fuente de la
aplicación Citrine. Si sospecha de un problema de seguridad que afecte a Citrine,
comuníquese en privado con **support@citrineedge.com** e incluya una descripción
breve, la versión afectada de la aplicación y pasos de reproducción sin datos sensibles.

No abra un reporte público con detalles de explotación, credenciales,
registros de cuentas o información de otra persona. No envíe claves API, tokens
de compra, contraseñas ni documentos fiscales o bancarios. Si una credencial
puede haber quedado expuesta, revóquela mediante el servicio emisor; no espere
una respuesta de asistencia para protegerla.

Este documento no autoriza pruebas en cuentas ajenas, pruebas intrusivas contra
infraestructura de producción ni acceso a sistemas privados. No establece un
compromiso de pago de recompensas por vulnerabilidades ni garantiza un plazo de respuesta.
